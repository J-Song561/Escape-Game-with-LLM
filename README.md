# Chat: The Only Way Out

##### 생성형 언어 모델을 기반으로 플레이어와 NPC 간의 자유로운 대화를 구현한 추리 탈출 게임입니다. 플레이어는 NPC와 직접 대화하며 단서를 수집하고 탈출 방법을 추론할 수 있습니다.
##### "Chat: The Only Way Out" is an escape room mystery game featuring free-form conversations between players and NPCs powered by a generative language model. Players can interact directly with NPCs, gather clues, and deduce how to escape.
