# Chat: The Only Way Out

### ✨프로젝트 소개

##### 생성형 언어 모델을 기반으로 플레이어와 NPC 간의 자유로운 대화를 구현한 추리 탈출 게임입니다.
##### 플레이어는 NPC와 직접 대화하며 단서를 수집하고 탈출 방법을 추론할 수 있습니다.
##### "Chat: The Only Way Out" is an escape room mystery game featuring free-form conversations between players and NPCs powered by a generative language model. Players can interact directly with NPCs, gather clues, and deduce how to escape.

### ✨ 주요 기능
- **LLM 기반 NPC 대화 시스템:** 플레이어의 자연어 입력을 분석하고 맥락에 맞는 NPC 응답 생성
- **NPC 페르소나 구현:** 캐릭터별 성격과 배경 정보, 지식 범위를 반영한 차별화된 응답 구현
- **RAG 기반 정보 검색:** 캐릭터별 설정 및 게임 내 정보를 검색하여 응답 생성에 활용
