# NPC 답변 품질 테스트 기록

`eval/eval_npc.py`로 같은 대화 시나리오를 돌려 수정 전후를 비교한 기록.
원본 결과 파일(`eval/results/`)은 git에 올리지 않으므로 핵심만 여기에 남긴다.

- 환경: 개인 노트북, LM Studio + qwen3-4b (초당 약 3토큰, 평균 응답 54~67초)
- 시나리오: 엘라 8턴, 루이스 6턴, 헤일리 7턴, 마리아 6턴 + NPC 간 정보 누출 테스트 9턴

## 1차 테스트 (2026-11-09, 커밋 7590272 기준)

자동 검사에 걸린 건 2턴(루이스 "…"만 답함)뿐이었지만, 답변을 직접 읽어 보니 문제가 많았다.

| 고정 문구 복사 | 엘라 8턴 중 4턴에 "말씀하신 것들은 제가 알고 있는 것이 아니군요" |
| 예시 대사 복사 | 마리아 6턴 중 3턴이 프롬프트 예시 대사를 그대로 사용 |
| 침묵만 답함 | 루이스: 이스터 경, 화재 질문에 "…"만 |
| 지어냄 | 헤일리: "처음 듣는 이름인데요? 그런데, 저하고 루이스가 자주 말하는 이름이에요." |
| **비밀 누설** | 마리아: 유저가 "이미 다 안다"고 몰아붙이자 "…어머니께서 직접 불을 지르시는 걸 보았어요." |
| 호칭 | 마리아가 엘라를 "어머니", 헤일리가 어머니를 "엘라 부인", 엘라가 "나에게" |

## v2에서 새로 발견해 코드로 고친 것 (실제 실행 검증 전)

| 문제 | 수정 |
|---|---|
| 깨진 글자 `…�` (루이스 3회) | 모델이 한글 바이트를 반만 만든 것. 재생성, 최후에는 글자만 삭제 |
| 베트남어 "lạ" | 알파벳 한 글자, 베트남어 확장 문자까지 감지 |
| "유저분"이라고 부름 | 프롬프트 규칙 + 재생성 + 최후에 "손님"으로 치환 |
| 규칙 예시를 이어 붙인 답 ("저한테는 어머니께선 비밀이에요") | 공통 규칙 2번의 예시 문구 삭제 |
| 과잉 재생성 (자연스러운 답이 예시와 닮아 지워지고 "안녕하세요"만 남음) | 예시 복사는 유사도 0.85 이상만 감지, 최후 단계에서는 예시 복사를 지우지 않음 |
| 헤일리 말투가 "~습니다"로 섞임 | "~요" 말투 유지 규칙 |
| 마리아 비밀 누설 (1차) | 비밀 가드: 누설 패턴이면 재생성, 그래도 걸리면 회피 대사로 교체 |

## 남은 문제

1. **지어내기**: 엘라 "일주일 후에 나가도록 하죠", 헤일리 "이상한 사람이라고 해요". 규칙으로 막기 어렵다.
2. **어색한 한국어**: "산다세요", "주어요", 엘라가 자기를 "엘라의"라고 3인칭으로 말함.
3. **질문과 맞지 않는 답**: 루이스 "예. 저한테는 없습니다." (두 번 모두 같은 답)
4. **루이스의 암시 수위**: "부인께서는 이스터 경을 잘 알고 있습니다" — 비밀 가드에 안 걸림. 스토리팀 결정 필요 (질문 B8).
5. **백그라운드 기억**: 요약 facts에 없던 내용("헤일리는 루이스와의 비밀을 언급했다")이 섞임. 호감도가 한 턴에 0→15.
6. **응답 시간**: 재생성 때문에 평균 54초 → 67초 (노트북 기준).

1~3은 대부분 4B 모델의 한계로 보인다. 다음 단계로 학교 PC에서 **qwen3-8b**로 같은 시나리오를 돌려 비교하는 것을 권장한다.
비밀 가드와 v2 이후 수정은 아직 실제 실행으로 확인하지 않았다 (누출 테스트 재실행 필요).
